# 實機手動測試檢查清單（issue #20）

上線前在 **iOS Safari 17+** 與 **Android Chrome（最新版）** 的實機上各跑一次主要流程（PRD §7 瀏覽器支援）。
自動化測試（Vitest、Playwright 的 Mobile Chrome／Mobile Safari 模擬）已涵蓋功能與無障礙，這份清單只檢查模擬器測不到的部分：
真實的觸控與虛擬鍵盤、加入主畫面、真的斷網、實際網路下的載入速度。

## 準備

1. 在兩台裝置上清除這個網站的資料（iOS：設定 → Safari → 進階 → 網站資料，刪除 `re757575.github.io`；Android：Chrome → 網站設定 → 所有網站 → 清除並重設），從全新狀態開始。
2. 若之前已加入主畫面，先把圖示刪掉。
3. 結果欄填 ✅（符合）、❌（不符合，於備註寫下實際狀況並附截圖）或 —（無法測試，寫明原因）。
