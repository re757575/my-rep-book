# 重量一律以 kg 儲存，lb 輸入換算後不四捨五入

重量單位只影響顯示與輸入：所有重量（組的重量、額外負重、體重）一律以 kg 儲存，lb 模式下輸入的值以 1 lb = 0.45359237 kg 換算後原樣儲存，只在顯示時四捨五入到 0.1。另一個做法是依輸入時的單位儲存並記下單位，但那樣每個計算（訓練量、上次紀錄、個人紀錄、統計）都得逐筆換算，混用單位的紀錄也難以比較。不在儲存時四捨五入，是為了讓 lb 使用者輸入 135 後重新顯示仍是 135，而不是先存成 61.2 kg 再換算回來的 134.9。

## Consequences

- 儲存的 kg 值會出現像 61.23496995 這樣的小數，這是預期的，不是資料錯誤。
- 備份檔中的重量也都是 kg，不帶單位欄位。
