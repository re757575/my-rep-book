# 預設動作是程式碼常數，ID 為發佈後不可更改的 slug

預設動作寫在 `src/domain/presets.ts`，不存進 IndexedDB，ID 是固定的 slug（例如 `barbell-bench-press`）；資料庫只記下使用者隱藏了哪些預設動作。這樣更新預設動作庫（改名、補英文名稱、調整部位）只要發佈新版，不用寫資料遷移。代價是訓練與備份檔都以 ID 引用預設動作，所以 slug 一旦發佈就不能更改或移除。

## Consequences

- 匯入的備份檔引用了不存在的動作 ID（例如較新版本才有的預設動作，或被移除的 slug）時，整份拒絕匯入並列出缺少的 ID，而不是略過那些訓練動作。
- 要淘汰一個預設動作，只能讓它不再出現在列表，ID 仍須保留。
- 自訂動作的 ID 以 `custom-` 開頭，不會與預設動作的 slug 衝突。
