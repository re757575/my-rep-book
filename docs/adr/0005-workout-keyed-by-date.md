# 訓練以日期為主鍵，一天一筆

一筆訓練對應一個本地時區的日期（`YYYY-MM-DD`），日期就是主鍵，同一天不能有兩筆訓練。這讓「今天的訓練」「補記某天」「月曆上哪幾天有練」都能直接以日期查詢，網址也能是 `/day/2026-10-20`。我們放棄了一天多個 session（例如早上重訓、晚上有氧分開記錄），因為個人使用的情境中，把它們放進同一天的訓練就足夠。

## Consequences

- 要支援一天多個 session，必須把主鍵改成 ID、遷移資料庫與備份檔格式，並重新定義上次紀錄與每日摘要以哪個 session 為準（列在 PRD §11 v2 規劃）。
- 「今天」以使用者裝置的本地時區判定；跨時區旅行時，同一次訓練可能落在不同的日期。
